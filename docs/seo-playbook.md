# 参考站分析与爆火点

## AIHub 为什么能排上来

从抓取结果看，`aihub.cn` 是 WordPress 工具站，已经有约 3000 篇内容，它的单页结构是固定的：

```text
面包屑 + H1 + 分类/标签 + 目录 + 是什么 + 主要功能 + 适用场景 + 定价 + 如何使用 + FAQ + 相关推荐 + 热门榜
```

它的核心不是“文章质量惊艳”，而是程序化 SEO：

- 每个 AI 产品独立一页，命中“产品名 + 是什么/怎么样/免费吗”这类长尾词。
- 大量分类页、标签页、相关推荐和热门榜互相内链，把权重导给新文章。
- 固定模板让自动化生产成为可能，内容可以每天滚动更新。
- FAQ 和结构化数据让搜索结果更容易出现富摘要。
- 域名年龄、内容量和更新频率形成整体权重。

## 我们复刻什么、不复刻什么

复刻：

- 单工具固定内容模板
- 分类页、标签页、相关推荐、热门榜
- sitemap、RSS、FAQ 结构化数据
- 每天固定发布两篇，保持新鲜度
- 广告位布局（详情页正文前后、侧栏、列表页）

不复刻：

- 不搬运 AIHub 的原文，它有版权声明，直接采集会有风险。
- 不照抄网站品牌、logo 和域名。
- 不用纯 AI 垃圾内容灌量；广告平台和搜索引擎都会压制无价值页面。

## 分类策略

只保留 `AI资讯` 和 `AI工具` 两个分类：

- `AI资讯` 是自动博客主线，模型发布、Agent 生态、厂商动态都归这里，每天固定 2 篇，页面显示发布日期。
- `AI工具` 收纳豆包、DeepSeek、即梦、LiblibAI 等热门工具，工具卡片不显示日期，避免页面看起来像内容农场。
- 聊天、编程、智能体、绘图、视频生成等旧子分类统一 301 到 `AI工具`，把权重集中到少量分类页。

工具页一定要使用官网真实图标，不要用字母块代替；详情页可同时展示官网和 `recommendUrl` 推荐链接。

## 上线前清单

1. 注册自己的域名，配置 HTTPS。
2. 部署到服务器，设置 `SITE_URL` 为真实域名。
3. 在 `/admin` 后台设置管理密码并创建 API 密钥，把完整 `ait_...` 填入 `XIAOLONGXIA_API_KEY`。
4. 提交 `sitemap.xml` 到 Google Search Console 和 Bing Webmaster。
5. 让“小龙虾”先跑一周真实、可核验的内容，再申请 AdSense。
6. 广告审核通过后填 `ADSENSE_CLIENT` 与各 `ADSENSE_SLOT_*`，替换 `ads.txt` 占位 ID。
7. 记录每条内容的来源链接，保留人工抽查机制。

## 内容优先级

先做容易产生搜索量的三类：

- 新发布的 AI 模型、Agent、开源框架
- 热门工具的更新：新功能、新定价、新版本
- “XX 好用吗 / XX 免费吗 / XX 怎么用”的对比与答疑页

每天两篇的节奏，一篇追热点，一篇补长尾，是最稳的组合。热点篇优先放进 `ai-news`，长尾答疑页按情况放进 `ai-tools` 或作为单条资讯处理。
